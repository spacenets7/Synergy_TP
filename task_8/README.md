# Task 8 — Descriptive Statistics and Technical Interpretation

## Objective
Understand descriptive statistics as tools for reasoning about Biochemistry, Electronics, and Mechanical measurement data — what summary numbers reveal, what they hide, and when a conclusion is only valid once units, sample size, outliers, and domain context are accounted for.

## Learning Resources Used
- OpenIntro Statistics — numerical summaries, distributions, variability, association: https://www.openintro.org/book/os/
- Khan Academy — mean, median, standard deviation, IQR, distributions, scatter plots: https://www.khanacademy.org/math/statistics-probability
- NIST Engineering Statistics Handbook — Exploratory Data Analysis and graphical methods: https://www.itl.nist.gov/div898/handbook/eda/eda.htm
- StatQuest — variance, standard deviation, correlation, histograms, box plots (optional support videos)

## Short Note on What Was Learned
The biggest shift was realizing a statistic can be arithmetically flawless and still be the wrong thing to report — a tight standard deviation from five readings, an outlier deleted on sight, or an average taken across variables that don't share a unit are all cases where the math is correct but the conclusion isn't. Sample size, units, and experimental condition aren't footnotes to a statistic, they're what make it mean anything at all.
